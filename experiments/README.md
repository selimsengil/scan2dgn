# Experiments (archived)

These scripts are kept as a record of what was tried. They are not maintained, and some expect local model
servers or files that are not part of this repository. Results and conclusions are in
[../docs/LESSONS.md](../docs/LESSONS.md).

| Prefix | Topic |
|---|---|
| `qwen_*`, `kapi_bul`, `karar_test`, `grounding_test`, `gorunum_test` | Local Qwen VLM: room geometry, grounding, decisions, views |
| `ds_*`, `deepseek_*`, `kat_agent_api` | DeepSeek agent loops, local and API backends (keys are read from the environment only) |
| `spec_*` | Specialist models: SAM2/SAM3, Raster2Seq |
| `kod_*`, `koseler`, `snap`, `walls` | Encoded "piece package" given to large models |
| `atolye_*`, `teach_*`, `compare_*` | Teaching and comparison harnesses |
| `bench*`, `capacity_test`, `gguf_*`, `token_say` | Inference speed and memory benchmarks |
